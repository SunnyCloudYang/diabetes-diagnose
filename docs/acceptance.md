# 第一版验收约定

本项目用于科研演示。数据仅来自用户提供的 CSV 和字段说明图。不存在 2025 年数据，不接入外部环境或医学知识库。

## 数据与模型

- 原始受试者行、身份编号和脱敏精确坐标不进入浏览器资源或版本控制。训练命令读取显式给定的本地 CSV。
- 训练与验证按受试者隔离；预测特征来自预测起点，不使用结局时的体检数据、未来体检总次数或未来信息。
- 区间、事件、删失、预测期限及算法假设在技术方案和生成报告中说明。未观察到事件不自动视为任意未来期限的阴性。
- 性能指标从独立保留数据实际计算；标明内部验证与样本量。研究分层不冒充临床阈值。
- 缺失处理和缩放参数仅由训练数据拟合；浏览器与离线模型的同一输入推断结果一致。
- 固定环境情景源自完整的真实历史暴露向量；展示确切窗口与污染物累计年份，不拼接为虚构的 2024 自然年数据。
- 模型贡献说明其计算尺度与参考值，不等同于因果效应或干预获益。

## 网站行为

- 首次打开不显示捏造的个人预测结果；填写信息并主动提交后才显示结果。
- 示例输入明确标记为演示数据，不公开真实受试者的成套个人指标。
- 验证必填、数值范围、非有限值及不适用状态。输入异常不生成成功结果。
- 修改输入后，旧结果必须明确标记为旧输入结果或隐藏，避免新输入和旧概率同时被当作同一评估。
- 页面标明预测期限、历史环境背景、模型版本和研究限制。已确诊者不进入新发风险计算。
- 风险分层与环境暴露分级分开。一般健康教育独立于模型解释，附权威来源；不生成个体化治疗方案、因果或干预获益结论，不接入 RAG、实时定位或未来趋势。
- 用户体检输入与结果仅驻留当前浏览器会话内存；无外发、持久化存储或健康数据分析埋点。
- 重置清除输入与结果；如支持本次会话对比，需要明确记录对应输入和版本，且不混淆与真实随访。

## 验证

当前交互要求（替代先前单页录入约定）：基本信息、体检指标、血脂指标、核对计算分页呈现；逐页校验，往返保留值，提交前可核对。结果页包含分层解释、输入完整度、历史情景和一般健康教育建议；无宣传式导语。桌面与移动端使用一致的顶部导航、清晰焦点和可读字号。

- 前端类型检查及生产构建通过。
- 用有意义的测试验证未来标签隔离、受试者划分、模型公式、边界/缺失行为及 Python/TypeScript 数值一致性。
- 浏览器走通填写、示例、校验、提交、结果、编辑、重置及页面导航。
- 至少检查桌面和窄屏布局、键盘可操作性、标签关联、焦点及控制台错误。
- 浏览器网络请求只包含本机静态资源；产物检查无原始患者数据和个人编号。
- 保留可复现的训练、测试、构建和启动说明。任何未通过的检查明确记录。
