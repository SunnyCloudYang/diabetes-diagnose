# 糖尿病历史队列科研演示：技术方案 V1

状态：实现契约。本文只规定数据、模型、界面和验收边界，不把结果解释为临床诊断或经外部验证的风险概率。

## 1. 目标与明确边界

V1 用现有纵向体检队列建立一个可复现的内部研究演示：用户录入一次体检信息，在一个固定、可追溯的历史环境背景下，得到未来 3 年“首次发现糖尿病事件”的模型估计，并能查看变量在模型线性评分中的贡献。

只使用以下两个附件：

- `兰州气象糖尿病研究数据_含寒潮温差累计污染物_完整版.csv`
- `微信图片_20260929012442.png` 中的字段释义

V1 不接入实时气象、2025 年数据、定位服务、医学 RAG、外部指南、登录、数据库或 LLM 密钥。浏览器不接收原始患者记录，也不上传用户填写的健康信息。

页面必须使用“3 年研究估计”“研究分位”等措辞。不得使用“确诊概率”“临床低/中/高风险”“医学验证”等说法。手动填写得到的结果只表示：在附件队列、固定历史环境和下述模型假设下，输入位于历史数据域内时的关联性估计。

`cohort_visit_event=1` 表示本次体检首次达到新发糖尿病定义，不是从该行向未来看的标签。事件访问本身的 `glucose` 和其他检查值属于结局时信息，禁止进入预测起点。

所有人的事件至多一次，事件均位于个人最后一条记录，事件后不再进入风险随访。`n_visits` 因与实际行数常不一致，既不能用于区间构造，也不能作为特征。

相邻访问构造后共有 14,057 个候选区间；其中 2 个间隔为 0 天，剔除后为 14,055 个有效区间、1,017 个事件，覆盖 10,258 名至少有一个正时间区间的受试者。训练程序必须重新计算并断言这些计数；另 1 名受试者没有有效正时间区间，只保留在总队列描述中。

字段释义没有完整提供实验室和污染物单位。页面使用 CSV 原字段名和中性中文名称，`glucose` 只称“glucose（原表数值，单位待数据提供者确认）”，不得自行补成“空腹血糖”。气温字段可按附件标为摄氏度，天数和次数可按附件标注；其余单位未知时显示“原表单位待确认”。

## 3. 分析对象与区间构造

### 3.1 排序与质量检查

每人按 `visit_date`、`visit_seq` 稳定排序。训练在产生任何特征矩阵前执行以下检查：

1. `subject_id`、`visit_date`、`cohort_visit_event` 必须存在；日期可解析，事件值只能为 0/1。
2. 每名受试者事件数不得超过 1；事件后不得再有记录。
3. 事件行必须是该受试者最后一行。
4. 记录所有相邻间隔小于、等于或大于 0 的数量；仅 `Δt > 0` 可建模。
5. `weather_window_end = visit_date - 1 天`，且包含首尾的窗口长度为 365 天。
6. 将原文件指纹和上述计数写入聚合训练报告。任何断言失败就停止训练，不静默修复。

### 3.2 区间定义

对同一人的每对相邻访问 `(i, i+1)`：

- 起点行 `i` 必须满足 `cohort_visit_event=0`；
- `Δt = (visit_date[i+1] - visit_date[i]) / 365.2425`；
- `Δt <= 0` 的区间剔除并计数；
- 区间结局 `y = cohort_visit_event[i+1]`；
- 所有输入特征只读取起点行 `i`；终点行只能贡献 `visit_date` 和 `y`。

因此，事件不是被假定为恰好发生在终点，而是只知道发生在上一次阴性体检之后、本次事件体检之前或当时。未事件区间表示到下次体检仍未发现事件。

## 4. 受试者隔离拆分

在构造可供模型使用的区间前，先按受试者划分集合。分层变量仅用于拆分，是“该受试者是否曾出现事件”，绝不进入模型。

拆分规则固定如下：

1. 将 `subject_id` 规范化为字符串并排序；
2. 对事件/非事件两个层分别使用 NumPy `default_rng(20260929)` 洗牌；
3. 每层前 `floor(70%)` 为 train，随后 `floor(15%)` 为 validation，其余为 test；
4. 同一受试者的所有区间只能进入同一集合；
5. 输出三集合的受试者数、区间数、事件数，并断言交集为空。

当前数据按该规则预期得到：

| 集合 | 全部受试者 | 有有效区间受试者 | 区间 | 区间事件 |
|---|---:|---:|---:|---:|
| train | 7,180 | 7,179 | 9,812 | 711 |
| validation | 1,538 | 1,538 | 2,090 | 152 |
| test | 1,541 | 1,541 | 2,153 | 154 |

所有插补值、截断点、中心、尺度、缺失指示列、正则选择和研究分位阈值只由 train 决定。Validation 只选择正则强度；test 只在模型和全部规则冻结后评估一次。V1 不在 train+validation 上重拟合，以免改变已经验证和导出的预处理契约。

## 5. 有限特征集

V1 只使用 13 个起点字段，避免在 1,017 个事件上堆叠大量强相关指标。

### 5.1 个体和实验室字段

| 字段 | 类型 | 手动输入 | 缺失行为 |
|---|---|---|---|
| `age` | 连续 | 必填 | 缺失阻止计算 |
| `sex` | 二元类别，女=0、男=1 | 必填 | 只接受原表两类；缺失阻止计算 |
| `hypertension_history` | 二元，0/1 | 必填 | 缺失阻止计算 |
| `BMI` | 连续 | 可选 | train 中位数插补并启用缺失指示 |
| `glucose` | 连续 | 必填 | 缺失阻止计算；`>=7` 不计算新发风险 |
| `TG` | 连续 | 与 HDL 成对选填 | 两者同时缺失时分别按 train 中位数插补并启用缺失指示；单独缺失阻止计算 |
| `HDL` | 连续 | 与 TG 成对选填 | 两者同时缺失时分别按 train 中位数插补并启用缺失指示；单独缺失阻止计算 |

起点区间中 `glucose` 无缺失且最大值为 6.99；所有 `glucose >= 7` 的现有行都属于同次事件访问。页面对 `glucose >= 7` 显示“超出无事件起点训练域，本演示不适用”，不返回概率，也不直接给出诊断结论。

TG 与 HDL 的缺失状态在训练区间中近乎完全绑定：两者都有 8,867 条、两者都缺 940 条、仅 TG 缺 5 条、仅 HDL 缺 0 条。独立缺失指示在训练域外组合上会产生不稳定外推；当前最终模型的单项缺失系数约为 TG `-2.196`、HDL `+2.226`，固定其他输入的审查用合成参考从“两者都有”约 10.0% 变为“仅缺 TG”约 1.16%、“仅缺 HDL”约 62.3%，而“两者都缺”仍约 10.3%。因此 V1 只支持“两者同时填写”或“两者同时留空”，单独填写任意一项必须阻止推断。这是训练支持域限制，不是医学规则。

|---|---|

以下字段不得进入特征矩阵：

- `cohort_visit_event` 及终点访问的任何检查值；

- `baseline_year`、`baseline_age`、`cohort_followup_years_from_baseline`；
- `visit_date`、`visit_year` 和全部 `annual_*`；
- 坐标、`location_grid_id`；
- `CO`、`NO2`、`O3`、`PM10`、`PM25`、`SO2` 当年值及所有 `*_level`；
- 气象阈值、窗口日期和污染累计年份等元数据。

这些字段可用于区间构造、质量检查或情景来源说明，但不能成为预测变量。

## 6. 预处理契约

对每个连续模型字段，在 train 区间起点上依次计算并保存：

1. 非缺失值中位数 `impute`；
2. 非缺失值的 1% 和 99% 分位数 `clipLow`、`clipHigh`；
3. 缺失值填入 `impute`；
4. 将填补后的值截断到 `[clipLow, clipHigh]`；
5. 在填补且截断后的 train 值上计算均值 `center` 和总体标准差 `scale`；
6. 标准化为 `z=(clip(x)-center)/scale`。

若 train 中某字段存在缺失，附加一个 `field__missing` 二元特征。当前快照预期为 `BMI`、`TG`、`HDL` 和 `PM25_cumavg_lag1` 产生缺失指示；实际以 train 统计为准并写入 artifact。`scale <= 1e-12` 时训练失败，不静默删除字段。

二元变量不标准化：`sex` 使用女=0、男=1，`hypertension_history` 保持 0/1。编码映射必须进入 artifact 和方法页。

浏览器端输入必须是有限数。对连续输入：

- 超出训练起点的完整观测最小/最大值时阻止计算；
- 位于完整观测范围内、但超出 `clipLow/clipHigh` 时允许计算，不过要明确显示“尾部输入已按模型边界截断”，并在本次结果保存该警告；
- 空字符串不能被转换为 0；允许缺失的字段必须以 `null` 表示并走缺失指示；
- `TG` 与 `HDL` 必须同时为有限数或同时为 `null`；一项有值而另一项缺失时阻止计算，并提示脂质指标需成对提供；
- 历史环境默认值完整，不将“未知环境”伪装成 0。

这套截断用于降低附件中极端值对小样本线性模型的影响，不代表医学正常范围。

## 7. 核心模型

### 7.1 选择

采用带 L2 正则的区间删失、分段常数风险模型。它等价于带 `log(Δt)` offset 的 complementary-log-log 二项 GLM，能够直接利用不等间隔，而不把事件访问当天的检查值泄漏到起点。

对区间 `j`：

```text
η_j = β0 + x_j β
λ_j = exp(η_j)                         # 每年条件风险率
p_j(Δt_j) = 1 - exp(-λ_j Δt_j)        # 该观察区间发现事件的概率
```

区间似然为：

```text
y_j = 0:  L_j = exp(-λ_j Δt_j)
y_j = 1:  L_j = 1 - exp(-λ_j Δt_j)
```

训练目标：

```text
sum_j[-log(L_j)] + alpha / 2 * sum_k(β_k^2)
```

截距不惩罚。使用 SciPy L-BFGS-B，从 `β=0`、`β0=log(事件数/总暴露人年)` 初始化。事件项使用 `log(-expm1(-a))`，其中 `a=exp(η)Δt`，避免小概率下的消减误差。训练必须断言目标有限、优化收敛、系数有限；失败就不生成前端 artifact。

### 7.2 正则选择

只比较预先固定的 `alpha ∈ {0.01, 0.1, 1, 10}`。每个候选只在 train 拟合，以 validation 的平均区间负对数似然选择。若差值在 `1e-6` 内，选择更大的 alpha。不得根据 test 调整 alpha、特征、截断或文案。

V1 不报告 p 值、显著性、优势比置信区间，也不进行逐步变量筛选。系数反映模型关联，不是因果效应。

### 7.3 3 年研究估计

对一次输入，在“当前输入和环境在预测期内保持不变、条件风险率恒定”的假设下：

```text
P_3y = 1 - exp(-exp(β0 + xβ) * 3)
```

这是模型外推到固定 3 年的估计。`exp(β0+xβ)` 是每年风险率，不得在界面上称为“一年概率”。V1 只提供 3 年期限，不让用户切换多个期限，以减少误读。

## 8. 默认 2024 历史环境

默认环境必须来自一条真实、完整且内部一致的历史环境向量，不能把各列中位数拼成一个从未出现过的组合。

选择算法固定如下：

1. 候选为 `visit_year=2024`、`cohort_visit_event=0` 且以下 19 个环境字段全部完整的行；当前共有 6,514 行。
2. 19 个字段为 13 个 365 天气象指标，加 `CO/NO2/O3/PM10/PM25/SO2_cumavg_lag1` 六项污染累计值。
3. 对每列计算候选中位数。距离尺度优先使用 IQR；IQR 为 0 时使用该列极差；极差也为 0 时该维距离记 0。
4. 计算每条候选到中位向量的缩放欧氏距离，选择距离最小的真实行。并列时按 `visit_date`、窗口起止日期、19 个环境值的字典序稳定选择。
5. 只导出该行的 19 个环境值、窗口、污染累计年份和聚合选择说明。不得导出 `subject_id`、`visit_id`、坐标或 grid。

当前快照选择出的默认向量对应：

- 体检日期：2024-05-22；
- 气象窗口：2023-05-23 至 2024-05-21，完整 365 天，体检当天不纳入；
- 污染累计窗口：2019 至 2023 年，共 5 年。

因此界面应写“2024 记录所对应的历史 365 天环境情景”，不能写“2024 全年气象”。默认值虽来自 2024 候选，仍是历史条件情景，不代表用户当前位置、当前天气或未来 3 年暴露。

## 9. 内部验证

### 9.1 主指标

主指标是 test 全部有效区间上的平均负对数似然，同时报告区间数、事件数和总暴露人年。它与训练似然一致，并使用实际 `Δt`。

补充报告 test 区间预测的平均概率和观察事件比例，但不将后者当作固定期限发生率。

### 9.2 严格的 3 年 landmark 可判定子集

固定期限指标只在能从访问记录判定 3 年状态的子集中计算。每名 test 受试者以其第一条非事件访问作为 landmark `t0`：

- `positive`：首次事件检测日期 `<= t0 + 3 年`；
- `negative`：在 `t0 + 3 年` 当天或之后存在一次明确的非事件访问，且此前没有事件；
- `interval_straddles_H`：最后一次 3 年前访问为非事件，而下一次首次事件在 3 年后；真实事件时间区间跨过 3 年，状态未知；
- `censored_before_H`：没有 3 年内事件，且最后一次非事件访问早于 3 年，也没有后续可证明 3 年时仍无事件的访问。

后两类必须排除。尤其不能因为事件检测在 3 年后就自动标成 3 年阴性。

当前全队列预期分类为：阳性 483、阴性 5,720、3 年前删失 3,585、事件区间跨 3 年 471。固定拆分后的 test 预期为阳性 75、阴性 893、3 年前删失 500、跨界 73，即可判定子集 968 人。训练报告必须给出实际计数和排除比例。

在该 test 可判定子集上报告：

- AUROC；
- AUPRC，并同时报告阳性率；
- Brier score；
- 使用 train 可判定子集预测值定义的 10 个风险分箱，在 test 中给出每箱人数、事件数、平均预测和观察比例；空箱保留为空；
- ECE，按 test 各非空箱人数加权。

这些名称统一写为“landmark 可判定子集的内部描述性指标”。由于排除了大量提前删失和跨界区间，它们不能证明全人群 3 年校准，也不能视为外部验证。

### 9.3 不确定性

可进行 200 次受试者级 bootstrap：landmark 指标按人重采样；区间 NLL 也先按人抽样，再带入该人的全部区间。若某指标少于 180 次有效重采样，或重采样中频繁缺少任一类别，则省略该指标的区间，只报告点估计和原因。不得生成看似精确但不稳定的置信区间。

## 10. 研究分位和解释

从 train 中每名有有效区间受试者的第一条起点记录计算 `P_3y`，以 33.3% 和 66.7% 分位数形成三个研究分位位置：

- 较低研究分位；
- 中间研究分位；
- 较高研究分位。

这只是相对该训练样本的排序。不得映射为临床风险等级，也不提供治疗或就医阈值。阈值和样本定义进入 artifact。

解释使用模型线性评分上的确定性贡献：连续或二元特征贡献为 `β_k x_k`，缺失指示另算一项。参考点必须逐类说明，而不能笼统称为“平均患者”：连续变量的参考是标准化后的 0（即该字段经 train 插补、截断后的中心）；`sex` 的参考是女=0；`hypertension_history` 的参考是无=0；缺失指示的参考是数据已提供=0。界面可把同一原字段的数值项与缺失项合并，显示相对上述模型参考点对线性评分的推高或降低。最多显示绝对值最大的 3 个推高项和 3 个降低项，并始终附带：

> 贡献表示这个模型中的关联方向和大小，不是因果效应，也不能推断改变某一项会带来同等风险变化。

不生成自由文本医学建议。字段说明和限制使用随版本固定的本地模板。

## 11. 前端模型 artifact 契约

训练只向前端导出一个聚合、版本化 JSON。最低结构如下：

```text
schemaVersion
modelVersion
generatedAt
sourceFingerprint { sha256, rowCount, subjectCount, dateMin, dateMax }
horizonYears = 3
algorithm { family, link, alpha, formulaVersion }
intercept
features[] {
  name, label, kind, encoding?, coefficient,
  impute?, clipLow?, clipHigh?, center?, scale?,
  missingIndicatorCoefficient?, observedMin?, observedMax?, unit
}
researchQuantiles { q33, q67, referencePopulation }
defaultEnvironment {
  selectionMethod, candidateCount, visitDate,
  weatherWindowStart, weatherWindowEnd,
  pollutionWindow { startYear, endYear, nYears }, values
}
trainingSummary { splitCounts, intervalCounts, missingRates, exclusions }
evaluation { intervalMetrics, landmarkCounts, landmarkMetrics, bootstrap }
limitations[]
```

artifact 不得包含：患者行数组、任意 ID、坐标、grid、个体日期序列、按人预测、原始输入文件路径。仓库和 `public/` 不得包含 CSV 或从 CSV 拆出的逐行文件。

隐私扫描至少检查：禁止键名及字符串值中出现 `subject_id`、`visit_id`、`lon_cgcs2000_masked`、`lat_cgcs2000_masked`、`location_grid_id`；禁止存在长度接近样本量的数组；禁止出现原始 ID 值样本。artifact 允许数据指纹、聚合计数、系数、统计量和单条匿名环境向量。

浏览器推断必须只读取 artifact：

```text
linear = intercept + Σ(coefficient * transformedValue)
         + Σ(missingIndicatorCoefficient * isMissing)
hazardPerYear = exp(linear)
p3 = -expm1(-hazardPerYear * 3)
```

JavaScript 结果限制在 `[0,1]` 仅用于浮点保护；若中间值非有限，显示模型错误而不是伪造 0 或 1。

## 12. 页面、状态与数据驻留

### 12.1 页面结构

1. **研究估计工作台**：说明适用人群、期限和历史环境；分“基本信息”“可选检查项”“历史环境情景”填写；首次进入无结果。
2. **结果与解释**：显示 3 年研究估计、研究分位、贡献、输入尾部/缺失警告、模型版本和环境窗口。
3. **方法与限制**：数据范围、区间定义、模型公式、内部验证、字段单位状态、完整限制和 artifact 版本。
4. **可选增强：情景比较**：如首版时间允许，可在内存中最多保留 4 个会话快照，逐项显示输入差异和模型输出差异，并明确“关联情景比较，不表示干预收益”。该功能不阻塞 V1 验收。

### 12.2 状态机

```text
idle -> editing -> validating -> result
                    |             |
                    -> blocked    -> stale（任一输入被修改）
reset ---------------------------------> idle
```

- `idle/editing` 不显示概率占位符；
- `blocked` 对缺失必填、非有限值、非法类别、超域值、`glucose>=7` 给出字段级原因；
- 结果后修改任何字段，旧结果立即隐藏或显著标为 `stale`，不能让新输入和旧概率看似匹配；
- `reset` 清除个人输入、结果以及已实现的比较快照，同时恢复默认环境；
- “演示示例”使用各健康字段的 train 聚合参考值组成一条明确标为“合成示例”的输入，不能复制真实患者整行；
- 页面刷新后全部个人输入和快照消失。

用户填写和结果只存在 React 内存状态。不得写入 localStorage、sessionStorage、IndexedDB、cookie、URL 查询串、日志、分析埋点或远端接口。生产页面运行后无数据 API 请求；唯一资源请求是同源静态文件。

## 13. 主要局限

方法页至少逐条显示：

1. 事件只在体检时被发现，真实发生日期未知；模型依赖区间内风险恒定和删失/复查机制可忽略等假设。
2. 模型使用历史队列中的复查者；复查时间可能与健康状况相关，不能代表兰州一般人群。
3. 3 年估计假设输入和环境条件保持不变；默认情景是历史向量，不是未来暴露预测。
4. 环境变量与年份、地区和其他未观测因素可能混杂；贡献不是气象或污染的因果效应。
5. 随机受试者拆分属于同一数据源内部验证，没有地理、时间或外部队列验证。
6. 固定期限指标只来自可判定子集，排除提前删失和跨界事件区间，存在选择偏差。
7. 实验室和污染物单位未完整确认；手动输入必须按原数据同一单位体系，字段含义待数据提供者最终确认。
8. 样本只有 1,017 个首次事件，特征和算法刻意保持简单；不得把研究演示用于诊断、治疗或个体医疗决定。

## 14. 实现与验收清单

### 14.1 离线训练

- 命令必须通过显式 `--data <csv>` 读取本地附件，不把绝对路径写入 artifact。
- 固定随机种子、依赖版本、源指纹、拆分算法和选中 alpha；相同输入重复运行时系数、指标和 artifact 字节一致，`generatedAt` 可通过可复现构建参数固定或从比较中排除。
- 生成聚合训练报告，列出所有纳入/剔除计数、缺失率、拆分数、优化状态和真实 test 指标。
- 指标计算失败或某类样本不足时显示 `not_available` 和原因，禁止填充示例 AUC/概率。

### 14.2 必需自动测试

1. **未来信息隔离**：改变任意终点检查值不会改变起点特征或预测；改变终点事件才只改变标签。
2. **区间构造**：同日区间剔除；不等间隔带入 offset；事件后没有新区间。
3. **拆分隔离**：受试者集合交集为空；预处理统计只由 train 产生。
4. **3 年标签**：事件在 H 前/等于 H 为阳性；H 后存在阴性访问为阴性；H 前阴性、H 后首次阳性的跨界区间为未知；H 前失访为删失。
5. **公式单元测试**：手算的事件/非事件似然和固定期限概率与实现一致，极小风险率下仍为有限数。
6. **Python/TypeScript 一致性**：至少 20 个合成输入和缺失组合，`p3` 绝对误差 `<=1e-10`。
7. **默认环境**：选择出的向量确实存在于候选数据；窗口恰为 365 天；污染累计年为 2019–2023；导出值不是逐列中位数组合。
8. **输入行为**：空字符串、NaN、Infinity、非法类别、超域、`glucose>=7` 均不产生成功结果；可选缺失走插补+指示；`TG/HDL` 两者都有和两者都缺可通过、仅缺任一项必须阻止；尾部截断显示警告。
9. **隐私产物**：Git/public 中无 CSV、无患者 ID/坐标/grid、无逐行数组；artifact 只含允许的聚合信息。
10. **界面流程**：首次无结果；填写、校验、提交、编辑变 stale、重置均正确；若实现可选比较功能则一并验证；桌面和窄屏可用；键盘焦点、label 关联和错误提示可访问。
11. **网络与持久化**：浏览器无外发请求；刷新与重置后用户输入和结果不保留。
12. **构建**：前端类型检查、测试、生产构建和从干净环境复现训练全部通过。

### 14.3 完成定义

V1 只有在真实训练完成并产生非占位 test 指标、artifact 通过隐私扫描、浏览器与 Python 数值一致、页面完整展示研究边界后才可称为完成。若训练或评估尚未运行，界面应显示“模型尚未生成”，不得用硬编码概率或虚构 AUC 代替。
